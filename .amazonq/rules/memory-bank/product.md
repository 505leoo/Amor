# Product Overview

## Purpose
"Amor" is a private couples app — a shared digital space built for two people in a relationship. It combines gamification, personalization, and real-time communication to create a unique intimate experience.

## Key Features
- **Pistas (Clues)**: An interactive gift-hunt game with 7 sequential puzzle challenges (multiple choice, word spelling, color sequence memory, etc.) that unlock scratch cards revealing a special date.
- **Inicio (Home)**: Main hub with animated room-like UI, stickers, messages, and a customizable background.
- **Ecos**: Shared emotional journal / mood board between partners.
- **Buzón**: Private message inbox between the couple.
- **Tienda**: In-app shop using virtual currency (dinero).
- **Trofeos**: Trophy/achievement system tracking relationship milestones.
- **Colección**: Photo/memory collection gallery.
- **Stickers**: Custom sticker system with Firebase Storage uploads.
- **Temas**: Visual theme selector with animated particle backgrounds (stars, golden particles, ocean, moonlight, sweetCake).
- **Perfil**: User profile management.
- **SeasonInfo**: Seasonal content and events.
- **Notificaciones**: Real-time push notifications via Pushy when partner connects or shares content.

## Target Users
A couple (two users linked via a `pareja` field in Firestore). The app is deeply personal — content, puzzles, and messages are tailored to the specific relationship.

## Value Proposition
A gamified, visually rich shared space that makes everyday couple interactions feel special — combining puzzle games, emotional check-ins, shared memories, and real-time presence awareness.
