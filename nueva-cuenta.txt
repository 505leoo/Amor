Checklist: cambiar/migrar a nueva cuenta EAS (resumido)

1) Autenticación
- eas logout
- eas login
- eas whoami

2) app.json / eas.json
- En `app.json`:
  - expo.owner = <nuevo-owner>
  - expo.extra.eas.projectId = <PROJECT_ID>
  
  - En "App.json" quitamos el projectId viejo y usamos "npx eas init".
  
  - expo.updates.url = https://u.expo.dev/<PROJECT_ID>
  - runtimeVersion = "<version-string>" (ej: "1.2.3")
- Sincronizar `package.json` version con runtimeVersion si usas script.
- En `eas.json`: revisar perfiles (production/preview/development) y opcionalmente añadir `cli.version`.

3) GitHub / CI
- En expo.dev → Settings → Version control, conectar el repo con la nueva cuenta/organización.
- Actualizar secrets/tokens en GitHub Actions con el token de la nueva cuenta.

4) EAS Update (canales y ramas)
- Ver canales:
  - eas channel:list
- Ver updates por rama:
  - eas update:list --branch <branch>
- Ligar rama a canal (si es necesario):
  - eas channel:edit    # interactivo, o usar la UI en expo.dev → Updates → Channels
- Publicar update con runtimeVersion correcto:
  - eas update --branch <branch> --message "<msg>" --platform android

5) Builds
- Confirmar credenciales (keystore, google-services.json) en la nueva cuenta/proyecto.
- Generar build:
  - eas build --platform android --profile production
  - eas build --platform ios --profile production

6) Verificación y debugging
- Comprobar endpoint updates desde PC:
  - curl -v "https://u.expo.dev/<PROJECT_ID>?runtime-version=<runtimeVersion>&channel-name=<channel>&platform=android"
- Logs en dispositivo:
  - adb logcat *:S ReactNativeJS:V dev.expo.updates:V | Select-String "\[Updates\]|\bdev.expo.updates\b"
- Asegurarse que `eas update:list --branch <branch>` muestre runtimeVersion que coincide con la app.

7) Errores comunes
- Canal sin ramas → "There are no branches linked to the channel"
- runtimeVersion desincronizado → cliente pide v1.x, updates publicadas con otra v
- app.json owner o projectId incorrectos → la app pedirá updates del proyecto equivocado
- Credenciales faltantes → builds fallan o pierden notificaciones

8) Comandos útiles resumen
- eas login / eas logout / eas whoami
- eas channel:list
- eas channel:edit
- eas update --branch <branch> --message "<msg>" --platform android
- eas update:list --branch <branch>
- eas build --platform android --profile production
- adb logcat *:S ReactNativeJS:V dev.expo.updates:V | Select-String "\[Updates\]|\bdev.expo.updates\b"
- https://profile.aws.amazon.com/#/profile/details
